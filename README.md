A premium, animated **cafe / restaurant website** — dark, moody, and motion-rich, built to win local hospitality clients.

### 🔗 [**View Live Demo →**](https://cafevita.vercel.app)

---

## ✨ Highlights

- **Smooth-scroll** experience (Lenis) with GSAP scroll reveals
- Cinematic hero with layered motion
- Menu, gallery, and catering sections
- Micro-interactions throughout, fully responsive

## 🧱 Tech stack

| Layer | Tech |
|-------|------|
| Framework | React 18 + Vite |
| Styling | Tailwind CSS |
| Motion | GSAP + Framer Motion |
| Smooth scroll | Lenis |

## 🚀 Run locally

```bash
npm install
npm run dev
npm run build
```
